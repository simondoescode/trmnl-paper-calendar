## Paper Calendar v0.2.0

- Embedded, licensed Manrope variable font; works offline in the self-contained plugin ZIP.
- Clearer weather SVGs and refined four-shade typography, event cards and forecast highs/lows.
- Hidden event counts for Today and Later this week; the footer includes all Today events.
- Multi-day labels: Until Friday, Continues, and accurate exclusive end dates.
- Stale cached weather is distinguished from unavailable weather, with the last successful update time.
- Inspirational quotes on empty days, selected consistently by date without network access.

Download **paper-calendar.zip** for the current production Liquid template and settings. Calendar exchanges still require private configuration in Terminus; the development backend is not included in this archive. Multi-day and stale-weather labels require the documented normalized metadata. Importing the exact ZIP into a running Terminus instance remains unverified.

Validated with 23 calendar/weather tests, three packaging tests, native Firefox layout/state checks, screenshot regression and TRMNL lint.
